# P3 — World build: landscape + World Partition + region C PCG (Nicko's PC)

Estimate: 16–24 editor-hours. Prereq: P2 assets in /Game/WH.

## Goal
The 4-region world standing in UE, streaming cleanly, region C procedurally dressed
by PCG with the same seed discipline as the browser.

## Steps
1. Landscape: import artifacts/ue-port/regionC_heightmap_1009x1009.png (16-bit,
   1009x1009 -> 16x16 components of 63-quad sections; scale Z per the meta
   heightRangeMeters span 38.22 m). Verify the den-mouth sink (-163.4,-202.6 world)
   + stone pad + rim silhouette against the meta + browser renders.
2. Regions A/B/D: flat-ground set dressing from CONFIG-dump.json rows
   (a data-driven spawner script consumes the dump; every row keeps its config id).
   A's boundaryWall ring -> skirt + blocker volumes.
3. World Partition: 512 m cell grid; A/B/C/D cells + HLOD layer enable.
4. PCG: 3 biome graphs (graveyard/edge, forest, den surround) seeded from
   CONFIG.scatter (20261005); road-edge dressing from the King's Roads rows; rock +
   ruin clusters from regionC rows. Mirror Epic's PCG Biome Sample patterns; don't
   ship its content.
5. Rim notches: carve + blocker volumes replicating wh-ground holdAtNotch
   (3 blockers + the door window).
6. Verify probe coords: convert CONFIG (x, z) -> UE (x, up, -z); walk 8 landmark
   checks (church gate, chokepoint, shrine, den mouth, 3 camps, 1 wolf loop).
