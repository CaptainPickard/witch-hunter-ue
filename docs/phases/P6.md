# P6 — Systems port: camp/save/cooking/daynight/inventory/leveling (Nicko's PC)

Estimate: 16–24 editor-hours. Prereq: P5 (enemies for cook/buff loops to matter).

## Goal
The survival loop in UE: place camp, cook with buffs, sleep at night, save/load,
inventory + leveling.

## Steps
1. UWHCookingSubsystem + Recipe DataTable (3-ingredient recipes + buffs from
   prototype/js/cooking.js; exact buffs into a DataTable from the VPS dump).
2. AWHCampKitActor: placement ghost, save/load, save-and-heal, dusk/night-gated
   sleep (gate: CONFIG camp rows; C11 ruling).
3. AWHDayNightManager: 100-min cycle; hook wolf night boldness + lighting presets.
4. UWHInventoryComponent + Item DataTables (gathering drops, corpse loot).
5. UWHLevelingComponent: XP curve from CONFIG.leveling rows.
6. UWHSaveGame schema v2: player transform/stats, inventory, camp, daynight clock,
   + a version hash of the CONFIG dump (config drift detection).

## Gate G-P6-1 (acceptance)
- [ ] Full loop: camp -> cook 3 recipes -> buffs visible -> save -> reload ->
       state restored -> sleep at night only (day sleep refused).
- [ ] Save schema round-trip stable across a respawn.
- [ ] Day/night cycle: 100 min verified with the lighting presets visible.
