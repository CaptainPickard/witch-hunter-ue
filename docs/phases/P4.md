# P4 — Player controller + Enhanced Input + combat core (Nicko's PC)

Estimate: 20–30 editor-hours. Prereq: P3 world walks.

## Goal
EPR1-feel player combat in UE: lock-on, 3-hit combos, parry/riposte, roll + stamina,
weapon kits, caster firebolt.

## Steps
1. AWHCharacterPlayer (C++): Enhanced Input actions (move/camera/lock-on/attack/
   roll/parry/cast/interact), camera rig matching the prototype's follow feel
   (CONFIG.player, CONFIG.mouse; lock-on cam behavior from CONFIG.lockOn).
2. AWHCombatComponent: the EPR1 contract — 3-hit chain chains with buffering, cancel
   matrix, backstep, release-to-roll, guard-raise blockActive, hit stagger, root
   motion tables (values from the dev commit 3f509e7 tables + CONFIG.moveset; use
   the erparity floor values as the acceptance reference, do NOT re-tune).
3. Weapon kits: sword/axe/dagger/shield + caster; socket mount per WH_Socket_*
   contract (doc 54) + CONFIG.weaponMount/shieldMount/torchMount numbers.
4. Caster: UWHCastComponent + Niagara firebolt (P4 placeholder VFX is fine; polish
   in P7). Hit register vs enemy capsule/parry window.
5. Playtest vs the browser prototype side-by-side (lock-on feel, chain rhythm).

## Gate G-P4-1 (acceptance)
- [ ] EPR1 floor values verified in-engine (erparity floor table exported to
       artifacts/ue-port/combat-parity.csv — VPS-side pre-work).
- [ ] 3-hit chain cancel/buffer matrix behaves per the browser contract.
- [ ] Lock-on target pick + camera behavior matches CONFIG.lockOn.
- [ ] Roll/stamina economy feels parity to v8 playtest.
