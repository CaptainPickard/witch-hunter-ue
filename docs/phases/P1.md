# P1 — UE project bootstrap + the pixelation gate (Nicko's PC)

Estimate: 6–10 editor-hours. Where: Nicko's PC (UE 5.8 or the pin from §13). First UE
session; everything else builds on it.

## Goal
A Blank C++ WHGame project that opens clean, with the art-law carrier (pixel register
post-process) proven on a test map — the single visual gate for the whole port.

## Steps
1. Install/verify UE 5.8 on the PC; create Blank C++ project WHGame (World Partition ON,
   512 m grid; Nanite OFF project-wide; Lumen ON default; Enhanced Input + CommonUI
   plugins enabled). Repo the project files into this repo (uproject + Source/ +
   Config/ + Content/ is gitignored except tracked manifests; see .gitignore).
2. Create `M_PP_WHPixelRegister` post-process material: SceneTexture:PostProcess0
   sampled on a stepped UV grid (fixed pixel register, e.g. 3-4 px at 1080p), then
   5-bit quantize floor(c*31)/31; optional doc-34 ordered-dither offset pre-quantize.
3. Make the `WH_Pixel8` texture group profile (nearest filtering) a project setting +
   Interchange import preset carrying it.
4. Test map `L_Gate1`: one prototype-matched corner scene (a graveyard patch + one tree
   + gravestones + the church gate) using 2-3 real GLBs via Interchange; place a
   reference camera matching one prototype v8 shot (browser render side-by-side).
5. Run the G-P1-1 gate (below). Record verdicts + screenshots in artifacts/ue-port/
   gate-p1/ (PC side), summarized into docs/phases/P1.md.

## Gate G-P1-1 (acceptance)
- [ ] Register/quantize look matches prototype v8 render side-by-side (banding equal).
- [ ] Color-ramp band histogram: 32 steps per channel, no 6-bit leftovers.
- [ ] No shimmer on slow camera pans (Lumen + stepped UV interplay OK).
- [ ] Nearest group profile verified on imported textures (no filtering drift).
- [ ] Project opens clean, PIE stable 60 fps on the test map.

## Outputs
- WHGame.uproject + Source/WHGame skeleton committed here (branch dev).
- gate-p1 verdict notes + screenshots.
